# P0.10 Apple Silicon grounded-locomotion baseline

**Measured:** 2026-08-27

This baseline measures the P0.10 capsule-query and proof-scene physics cost on the reference Mac. It is an in-process distribution, not a production concurrency claim or a substitute for the required Ubuntu result.

| Item | Value |
| --- | --- |
| Computer | Mac mini, Mac16,11 |
| Processor | Apple M4 Pro, 12 cores |
| Memory | 24 GB |
| Operating system | macOS 26.5.1 |

## Reproduction

Run the focused release probes after compilation:

```bash
cargo test -p verse-physics --release --test compound_grid_benchmark -- \
  --ignored --nocapture --test-threads=1
```

Run the complete native scenario:

```bash
GODOT_BIN=artifacts/toolchains/godot-4.7.2/Godot.app/Contents/MacOS/Godot \
  tools/e2e/verify-local.sh
```

## Results

Five consecutive serial release runs were sampled after compilation. The benchmark harness also holds a process-wide lock so future invocations cannot accidentally overlap probes. Each row reports the median of the five run-level values.

An earlier draft let Rust's test harness overlap the four ignored probes. Those contended values were discarded after the concurrency was identified; the results below are the serialized rerun.

| Measurement | Median result |
| --- | ---: |
| 2,048 static voxel colliders + one dynamic block, scene build | 0.465 ms |
| Same scene, one fixed step | 0.0024 ms |
| 2,816 static voxel colliders + 25-block dynamic grid, scene build | 0.701 ms |
| Same proof-budget scene, one fixed step | 0.0034 ms |
| Dirty 88-leaf chunk replacement, inner-sample median | 0.0123 ms |
| Dirty 88-leaf chunk replacement, inner-sample p95 | 0.0211 ms |
| Three-cast grounded set against 2,816 leaves | 0.0200 ms |
| One capsule cast within that set | 0.0067 ms |
| Complete protocol, restart, Godot, and impairment scenario | Passed |

The grounded set performs one support cast, one forward-obstruction cast, and one raised landing cast while ignoring the live character body. It therefore represents the expensive path of the P0.10 step solver; ordinary supported frames do not always need all three casts.

## Interpretation

- One active grounded controller plus the proof scene is comfortably inside a 16.67 ms server frame on this Mac.
- A naive linear extrapolation of the measured three-cast path is about 5.1 ms for 256 simultaneously stepping characters and 20.0 ms for 1,000. This is not a capacity result: broad-phase locality, scene density, persistence, replication, scheduling, and contention are absent from the probe.
- The thousands-of-players requirement still depends on cell partitioning, interest management, active/sleeping budgets, and multi-process scheduling. A single global physics scene is not implied by this result.
- The server-authoritative body translation used after successful step probes is constant-time in the adapter and preserves velocity. The probe does not separately time event validation, journal synchronization, or client replication.
- The exact recovery hash, conservation check, native prediction assertions, and Godot render smoke passed in the same P0.10 worktree after these measurements.
