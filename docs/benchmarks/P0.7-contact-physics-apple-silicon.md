# P0.7 Apple Silicon contact-physics baseline

**Measured:** 2026-08-27

This is the first reproducible Jolt and dirty-chunk rendering baseline. It establishes measurements, not production targets.

This historical measurement predates content `p0.7.2` and the native manifold listener. Its recorded timings remain the `p0.7.1` baseline and must be rerun before they are attributed to the newer adapter.

## Reference system

| Item | Value |
| --- | --- |
| Computer | Mac mini, Mac16,11 |
| Processor | Apple M4 Pro, 12 cores |
| Memory | 24 GB |
| Operating system | macOS 26.5.1 |
| Rust | 1.96.0 |
| CMake | 4.4.3 |
| Godot | 4.7.2 stable |
| Content manifest | p0.7.1 |
| Jolt | 5.0.0 through pinned `rolt`/`joltc-sys` 0.3.1 |

## Reproduction

Run the focused release probes:

```bash
cargo test -p verse-physics --release --test compound_grid_benchmark -- --ignored --nocapture
```

Run the complete native scenario:

```bash
GODOT_BIN=artifacts/toolchains/godot-4.7.2/Godot.app/Contents/MacOS/Godot \
  tools/e2e/verify-local.sh
```

## Results

Five consecutive release runs were sampled after compilation. The table reports their median.

| Measurement | Result |
| --- | ---: |
| 2,048 static voxel colliders + one dynamic block, scene build | 0.945 ms |
| Same scene, one fixed step | 0.065 ms |
| 2,816 static voxel colliders + 25-block dynamic grid, scene build | 0.933 ms |
| Same proof-budget scene, one fixed step | 1.540 ms |
| Same proof-budget scene, 120 steps | 184.811 ms |
| Fresh native 2,820-voxel asteroid, 32 render chunks | about 530 ms |
| One accepted voxel edit, 4 of 32 dirty render chunks | 73.529 ms |
| Complete protocol scenario | 52 accepted events, 144 fixed physics steps, 2 grids |
| Exact restart and fencing validation | Passed |
| Native Godot reconnect and snapshot render | Passed |

The compound probes included Jolt stepping and the then-current conservative swept-AABB/geometric contact telemetry. The 25-block body is a deliberately adversarial broad flat contact against a voxel plane; it is a scaling baseline rather than a typical orbital collision.

The initial render number rebuilds every asteroid chunk from a complete snapshot. One live mining sample rebuilt 4 of 32 chunks in 73.529 ms; an automated multi-sample edit-to-remesh distribution is still required before the P0 gate.

## Native-manifold follow-up (`p0.7.2`)

The same two release probes were rerun after replacing geometric contact
reconstruction with bounded native Jolt manifold capture. One sample produced:

| Measurement | Result |
| --- | ---: |
| 2,048 static voxel colliders + one dynamic block, scene build | 0.967 ms |
| Same scene, 120 fixed steps | 0.385 ms |
| Same scene, mean fixed step | 0.003 ms |
| 2,816 static voxel colliders + 25-block dynamic grid, scene build | 1.188 ms |
| Same proof-budget scene, 120 fixed steps | 0.471 ms |
| Same proof-budget scene, mean fixed step | 0.004 ms |

These post-hardening values include strict native-invariant checks, a callback
budget sized for both internal collision substeps, deterministic whole-record
contact selection, and rebuild-required poisoning after native errors. They are
focused in-process probes, not end-to-end capacity claims. They show that
removing the project-owned all-pairs geometric telemetry scan eliminates the
old proof scene's dominant per-step cost. A multi-sample distribution and
server persistence/replication measurements are still required.

## Interpretation and remaining evidence

- The proof-budget physics step fits within a 60 Hz frame on the reference Mac, but the server also performs validation, persistence, and replication work; this is not a production capacity claim.
- At this baseline revision, contact response was Jolt-owned while telemetry was geometric fallback. The later `p0.7.2` adapter captures native manifolds and a pre-solver pairwise estimate, which still cannot support production impulse damage without a post-solve binding.
- Ubuntu build/runtime results, multi-body scaling, network bandwidth, large-grid scaling, sparse edit-to-remesh latency, and persistence-boundary fault injection remain required.
