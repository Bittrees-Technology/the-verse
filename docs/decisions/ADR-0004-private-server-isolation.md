# ADR-0004: Private-server economic isolation

**Status:** Accepted

## Context

Private servers may use unrestricted mods and creative rules. Importing their assets would permit arbitrary resources to enter the official BIT economy.

## Decision

Private servers use separate universe and issuer namespaces. Their assets can never enter official inventories, contracts, custody, or markets.

## Consequences

- Private experimentation remains open.
- Canonical scarcity is protected.
- A private server may use BIT independently but receives no official asset certification.
