# ADR-0005: Location-specific AMMs

**Status:** Accepted

## Context

The economy depends on transport and regional scarcity. A global fungible ore token would teleport economic value between locations.

## Decision

Standardized commodities may use AMMs only through receipts tied to a specific market custody location. Unique goods use listings or auctions.

## Consequences

- Regional prices and logistics remain meaningful.
- Each pool requires real local custody and BIT liquidity.
- Pool fragmentation and low-liquidity markets must be handled in UX.
