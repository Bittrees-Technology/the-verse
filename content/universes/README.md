# Universe registry source record

`the-verse-local.registry.json` is an original proof-universe definition for
The Verse. It was created for this repository by the Bittrees Technology
project team and OpenAI Codex on 2026-08-27 from the project's accepted P1.5
requirements and clean-room celestial design.

- License: CC BY-SA 4.0 (`CC-BY-SA-4.0`).
- Required attribution: The Verse contributors.
- External source assets: none.
- Third-party game code, coordinates, names, art, and data: none.
- Purpose: deterministic proof-scale registry and validation fixture; it is not
  a claim of production planet scale or final interplanetary travel distance.

The registry's content hash is bound through the versioned universe manifest.
Changing an existing body identity or address requires an explicit migration;
new frontier content must use a newly published registry version.
