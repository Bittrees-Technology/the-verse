# Contributing to The Verse

The Verse welcomes design, engineering, art, testing, economic research, documentation, and governance contributions.

## Before contributing

1. Read the [documentation map](docs/README.md).
2. Find the relevant requirement and feature IDs.
3. Check [open questions](docs/open-questions.md).
4. Open or join an issue before beginning a large change.
5. Do not introduce copyrighted material from another game or franchise.

## Contribution flow

1. Propose the change and identify affected requirements.
2. Add or update an ADR for architecture changes.
3. Implement on a feature branch.
4. Add automated tests and migration notes.
5. Run formatting, validation, and security checks.
6. Open a draft pull request.
7. Receive maintainer and, when required, Verse DAO review.

## Changes requiring governance review

Governance review is required for:

- Canonical blocks, resources, recipes, or item schemas.
- Market or treasury behavior.
- BIT, bNOTE, bridge, escrow, or settlement behavior.
- Admin or Security Council powers.
- Official-server mods.
- Changes to economic isolation between private and official servers.
- Changes to asset destruction, salvage, cleanup, or insurance.
- Public API permission expansion.

## Developer Certificate of Origin

Contributions will use the Developer Certificate of Origin. Add a `Signed-off-by` trailer to commits to certify that you have the right to submit the work.

## AI-assisted contributions

AI-assisted work is welcome, but the submitting contributor remains responsible for correctness, licensing, security, and provenance. AI output must not be assumed original or safe without review.
